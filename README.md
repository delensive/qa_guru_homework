### `01 // О ПРОЕКТЕ`

**QA Guru Pet Project** — инженерный учебный полигон по автоматизации тестирования ПО на Python в рамках программы **QA.GURU**.

Репозиторий фиксирует эволюцию от базовых конструкций языка и работы с окружением до написания, поддержки и масштабирования автотестов с использованием **Pytest** и **Selenium WebDriver**. Новые модули добавляются в отдельные директории, не ломая общую инфраструктуру и правила качества кода.

---

### `02 // ОБУЧЕНИЕ И ВЕКТОР РАЗВИТИЯ`

* **Фундамент Python & Git:** уверенная работа с кодом, виртуальными окружениями, ветками и историей коммитов.
* **Автоматизация UI:** построение стабильных тестов на базе `pytest` и `Selenium WebDriver`.
* **Engineering discipline:** автоматический контроль стиля и чистоты кода через `black`, `isort`, `flake8` и `pre-commit` до попадания изменений в репозиторий.
